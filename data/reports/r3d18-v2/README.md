# R3D-18 v2: обучение завершено, перенос на другие источники слабый

28 сентября 2026. Дообучены готовые веса Kinetics-400 на разметке v2, где `bicycle_kick` включает боковые ножницы. Восемь эпох на CPU заняли около 16 минут вместе с итоговой оценкой; облачный GPU не использовался. Лучшая эпоха — пятая, выбрана по validation macro F1, затем по loss. Test не участвовал в выборе эпохи и порогов этого запуска.

**Test: 43 / 92 = 46,7%, macro F1 = 0,389.** Validation: 47 / 49 = 95,9%, macro F1 = 0,966. На test модель часто относит целевые действия к `other`. Результат хуже базового постоянного предсказания самого частого train-класса: 48,9%.

| Класс | Precision | Recall | F1 | Правильно / всего |
|---|---:|---:|---:|---:|
| Пас пяткой | 0,955 | 0,467 | 0,627 | 21 / 45 |
| Удар через себя / ножницы | 0,500 | 0,040 | 0,074 | 1 / 25 |
| Other | 0,309 | 0,955 | 0,467 | 21 / 22 |

Матрица ошибок: строки — истинный класс, столбцы — предсказание; порядок `backheel_pass`, `bicycle_kick`, `other`:

```text
21   1  23
 0   1  24
 1   0  21
```

Пороги для поиска, выбранные только по validation: пас пяткой **0,60**, удар через себя **0,95**. Эти оценки не откалиброваны как вероятности. Порог применяется дополнительно к требованию, чтобы целевое действие было первым классом модели.

## Данные и ограничения

- 204 train, 49 validation, 92 test; известные события и связанные окна не пересекают части.
- Источники target-классов train/validation — два сборника, test — другие два. 108 отрицательных окон HF распределены по матчам. Все метки предварительные.
- Test уже оценивался в v1, затем менялись его разметка и состав. Это пересмотренный известный набор, а не новый независимый тест.
- Прежние 59,0% на 78 клипах и текущие 46,7% на 92 клипах получены на разных составах и правилах класса; их прямое сравнение не измеряет эффект одной только переразметки.
- Большой разрыв validation/test совместим с переобучением и зависимостью от оформления источника; конкретная причина отдельно не установлена.

Следующее улучшение требует положительных и отрицательных действий из более разнообразных одинаковых источников, проверки пропущенных событий и отдельных новых матчей для оценки. Снижение порога само по себе не решает ошибочную классификацию действий как `other`.

- Пас пяткой: `ubXxfPPrMm0` и `I9cb9xWf2AA` — срабатываний нет.
- Удар через себя: `Cc5-xn17Sf8` — один фрагмент 41–44 с, оценка 0,966; `xE39aT_SDWs` — срабатываний нет.

В 16 кадрах входного окна 41–44 с визуально присутствуют удар через себя и приземление. В браузере проверены загрузка предпросмотра с 41-й секунды, запуск воспроизведения, ссылка YouTube с таймкодом, список найденных роликов и пустая выдача для пятки. HTTP Range возвращает `206`.

Это проверка работы сервиса. Новые сборники содержат знакомые события, а все пропущенные действия не размечены; по этому запуску нельзя оценивать независимую precision/recall поиска. Сводка запросов, источников, версий модели и результатов — `internet-smoke.json`.
