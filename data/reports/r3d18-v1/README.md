# Первый эксперимент R3D-18

**Итог на test: 46 из 78 верных ответов, accuracy 59,0%, macro F1 0,554.** Качество пока недостаточно для надёжного автоматического поиска.

| Класс | Precision | Recall | F1 | Клипов |
|---|---:|---:|---:|---:|
| Пас пяткой | 95,7% | 53,7% | 0,688 | 41 |
| Удар через себя | 40,0% | 33,3% | 0,364 | 18 |
| Other | 45,0% | 94,7% | 0,610 | 19 |

Precision показывает долю правильных ответов среди предсказаний класса, recall — долю найденных примеров среди истинных примеров этого класса. Эти значения рассчитаны по первому предсказанному классу на коротких клипах, без порогов поиска в длинном видео.

Матрица ошибок: строки — настоящая метка, столбцы — ответ модели.

| Настоящая метка → ответ | Пас пяткой | Через себя | Other |
|---|---:|---:|---:|
| Пас пяткой | 22 | 9 | 10 |
| Через себя | 0 | 6 | 12 |
| Other | 1 | 0 | 18 |

Простой ответ «пас пяткой» для любого клипа дал бы accuracy 52,6%. Модель пропускает почти половину пасов пяткой и две трети ударов через себя. Высокая precision пасов относится только к этой небольшой тестовой выборке.

## Как получен результат

- Train: 185 клипов; validation: 44; test: 78. Состав выборок сохранён.
- Восемь эпох: две для классификатора и шесть для последнего блока `layer4` вместе с классификатором.
- Выбрана четвёртая эпоха по validation: accuracy 97,7%, macro F1 0,982.
- Пороги поиска выбраны на validation: 0,80 для паса пяткой, 0,95 для удара через себя.
- Test оценён после выбора весов и порогов; настройки по его результату не менялись.
- Обучение и итоговая оценка заняли около 15,9 минуты на CPU. Brev не использовался.
- Модель: `models/r3d18-v1/best.pt`, SHA-256 `5f166c895a4fb6c746a584a998373ff09b03f95e9a29efc2c69f0f90c57a39cf`.

Большой разрыв между validation и test показывает слабый перенос на другие исходники. Возможные причины — особенности монтажа и трансляций, малое число независимых событий и предварительные метки. Этот эксперимент не устанавливает вклад каждой причины.

## Проверка поиска в интернете

В интерфейсе выполнены два реальных поиска по 30 секунд на видео. Поиск паса пяткой обработал один новый ролик и не дал срабатываний. Поиск удара через себя обработал три новых ролика и выдал четыре предложения модели. Проверены загрузка, HTTP Range, начальные таймкоды видеоплееров, воспроизведение и восстановление сохранённой выдачи по ссылке задачи.

**Обнаружено ложное срабатывание:** `Cc5-xn17Sf8`, 5–8 секунд, score 0,952. Все 16 входных кадров этого окна показывают заставку `TOP 10 / BICYCLE KICK GOALS`, без игрового действия. Эти четыре предложения нельзя считать четырьмя правильными находками. Пороги и модель после наблюдения этой ошибки не менялись. Связанные ID и результаты записаны в `internet-smoke.json`.

## Следующее улучшение

Проверить метки целиком, добавлять все три класса из одинаковых матчей и источников, объединять повторы одного события. Для следующей независимой оценки собрать новые матчи: текущий test уже просмотрен как результат эксперимента. Отдельно нужны размеченные длинные записи, чтобы измерить ложные срабатывания, пропуски и точность границ найденных моментов.

Полные числа — в `report.json`, ответы по каждому тестовому клипу — в `test_predictions.json`, история эпох — в `history.json`. Ограничение HF-части данных: некоммерческое исследовательское использование.
