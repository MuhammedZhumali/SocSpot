# SocSpot: первая разметка футбольных действий

**Текущий этап: подготовка данных и экспериментальное разбиение. Модель ещё не обучена, её точность не измерялась.** Автоматический поиск новых роликов в интернете и распознавание внутри них — следующий этап, описанный в [схеме обучения и поиска](docs/model-and-search.md).

Из четырёх локальных сборников подготовлены **263 коротких клипа** с предварительной разметкой:

| Метка | Клипов | Кандидатов после исключения связанных повторов |
|---|---:|---:|
| `backheel_pass` — пас пяткой | 153 | 139 |
| `bicycle_kick` — удар через себя | 61 | 55 |
| `other` — другие действия | 6 | 5 |
| `uncertain` — требуется проверка | 43 | 0 |

Всего около 14 минут нарезки. Число клипов **не равно числу независимых игровых событий**. Найдены и сгруппированы 24 повторных или предположительно повторных фрагмента; проверка дублей пока неполная.

## Посмотреть результат

Откройте `dataset-review.html` в браузере двойным щелчком. Он работает локально, без сервера и загрузки видео в интернет. Есть фильтры по классу, поиск, замедление, переход к действию и ссылки на исходник с таймкодом. Сами клипы находятся в `videos/clips/`, по папкам классов.

Страница предназначена для просмотра. Изменения разметки вносятся в `data/review_decisions.json`; затем нужно пересобрать индекс и повторить экспорт. Страница не сохраняет правки.

Если браузер не открывает локальное видео, запустите из корня проекта `python scripts/serve_review.py` и откройте `http://127.0.0.1:8765/dataset-review.html`. Этот сервер поддерживает HTTP Range для перемотки видео и доступен только на вашем компьютере. Остановить его можно через Ctrl+C.

## Что означают метки

- **Пас пяткой:** передача мяча партнёру пяткой. Удары пяткой, ведение мяча и передачи плечом сюда не входят.
- **Удар через себя:** удар в прыжке с отклонением назад. Пока принято узкое определение: боковые «ножницы» помещены в `uncertain`, пока не согласована граница класса.
- **Other:** несколько сложных отрицательных примеров из этих же роликов: например, удар пяткой, финт и передача плечом. Это ещё не полноценная выборка фоновых действий.
- **Uncertain:** техническая очередь проверки. Не использовать как четвёртый класс и не переименовывать автоматически в `other`: здесь могут быть целевые действия.

## Как получены таймкоды

Сборники визуально просмотрены через обзорные листы кадров с шагом 2 секунды и подробные последовательности с шагом 0,5 секунды вокруг выбранных эпизодов. Окна подобраны по этим кадрам с контекстом до и после действия. Это выборочная разметка эпизодов, а не покадровая разметка всего матча; отдельные действия могли быть пропущены.

Все метки имеют статус `provisional`, а проверка человеком — `pending`. `action_sec` — приблизительное время контакта/действия в исходнике, с точностью примерно до интервала выборки 0,5 секунды. Десятичные знаки не означают покадровую точность. Для коротких монтажных вставок контекст ограничен; это отмечено полем `short_context`.

В некоторых клипах остаётся склейка ракурсов или замедление, уже присутствующие в сборнике. Не все повторы экспортированы. Заставки, титры и большая часть празднований не вошли в нарезку. Кандидат № 97 из `smNANjh2t2Q` пропущен: он повторял конец предыдущего эпизода.

Имена игроков и команд в примечаниях служат навигации по видео; это не проверенная база идентичностей игроков.

## Файлы

- `data/sources.json` — четыре источника, YouTube ID, длительность, разрешение, FPS и SHA-256 исходных файлов.
- `data/annotations.json` — основной индекс: метка, путь клипа, исходный ролик, границы в секундах, время действия, группа повторов и статус проверки.
- `data/review_decisions.json` — редактируемые решения: `[номер, начало, конец, время_действия, метка, примечание, необязательная_общая_группа]`. Секунды относятся к исходному файлу.
- `data/seeds.json` — центры подробных последовательностей кадров; вспомогательный материал разметки.
- `data/dataset_summary.json` — актуальные количества после сборки индекса.
- `data/validation.json` — результат технической проверки каждого экспортированного клипа; создаётся командой `validate`.
- `videos/review/` — обзорные листы и кадры вокруг эпизодов.
- `scripts/video_dataset.py` — извлечение кадров, нарезка и проверка видео.
- `scripts/build_annotations.py` — сборка индекса и локальной страницы просмотра.

Исходные видео сохранены. Имеющееся имя папки `videos/bycicle_kick/` оставлено; в разметке используется правильная метка `bicycle_kick`.

## Повторить нарезку

Нужен Python 3.11 или новее. Например, в PowerShell из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-data.txt
.\.venv\Scripts\python.exe scripts/build_annotations.py
.\.venv\Scripts\python.exe scripts/video_dataset.py export
.\.venv\Scripts\python.exe scripts/video_dataset.py validate
```

FFmpeg поставляется с `imageio-ffmpeg`. Можно указать другой исполняемый файл через переменную `FFMPEG_BINARY`. Для текущей первой нарезки использован Python среды Codex, а локальная копия `imageio-ffmpeg` установлена в игнорируемую папку `.tools/python`.

Экспорт создаёт H.264 MP4 в исходном разрешении 1280×720, без звука, с CRF 18. FPS берётся из источника. Границы получаются перекодированием, а не копированием по ближайшим ключевым кадрам. `export` перезаписывает файлы текущего индекса; если поменять метку, старый файл в прежней папке останется — ориентируйтесь на индекс, а не на все MP4, найденные обходом папок.

Пример получения дополнительных кадров:

```powershell
.\.venv\Scripts\python.exe scripts/video_dataset.py sheets aVL9JkMTbV8 --start 5 --end 10 --step 0.25
```

## Перед обучением

1. Проверить метки и границы через страницу просмотра. Особенно просмотреть `uncertain` и короткие вставки.
2. Добавить разнообразные `other`: обычные пасы и удары, обработку мяча, борьбу, паузы. Датасет Hugging Face пока не скачан и не добавлен. Его фрагменты тоже нужно проверить на отсутствие целевых действий.
3. Завершить проверку совпадений между сборниками и по возможности добавить независимые матчи для оценки. Уже подготовлено экспериментальное разбиение ниже: тестовые исходники отделены, известные совпадения исключены из обучения. Полная независимость матчей ещё не подтверждена.

`training_candidate = true` означает лишь, что метка не спорная и это первый выбранный представитель известной группы. Это **не автоматическое одобрение качества** и не готовое разбиение для обучения. Четыре сборника с монтажом, замедлениями и узнаваемыми игроками пока не показывают, как модель будет работать на обычных записях матчей. Для распознавания самого удара через себя понадобятся также промахи и заблокированные удары, поскольку текущие сборники в основном показывают голы.

Модель на этом этапе не обучалась. Большие видео, кадры, локальные зависимости и виртуальное окружение исключены из Git; JSON-разметку и скрипты можно хранить в репозитории.

## Train, validation и test

Разбиение хранится в `data/splits/initial_source_holdout/`: `train.json`, `validation.json`, `test.json`, `excluded.json` и `summary.json`. Это списки путей к уже нарезанным клипам; видео не копируются.

| Часть | Пас пяткой | Удар через себя | Other | Всего |
|---|---:|---:|---:|---:|
| Train — обучение весов | 78 | 30 | 1 | 109 |
| Validation — выбор настроек и порогов | 20 | 7 | 1 | 28 |
| Test — оценка после выбора модели | 41 | 18 | 3 | 62 |

Для test отложены исходники `aVL9JkMTbV8` и `S-484NrAYuw`. Train и validation используют `smNANjh2t2Q` и `oA2pyZULjiM`. Если известный эпизод есть в тестовом сборнике, его представление из обучающего сборника исключается. В каждой известной группе выбирается один клип. В итоге исключены 43 спорных фрагмента и 21 повтор, включая шесть повторов тестовых эпизодов в обучающих источниках.

Результат воспроизводится командой `python scripts/split_dataset.py`. Настройки — `data/split_config.json`. Скрипт проверяет учёт всех клипов, существование выбранных файлов, непересечение известных событий и отсутствие тестовых исходников в train/validation. Хеши разметки и настроек записываются в манифесты. После изменения разметки повторно запустите скрипт и проверьте, что состав теста подходит для нового эксперимента.

**Это предварительное разбиение.** Train и validation используют те же два сборника; тест использует другие два, но невыявленные повторы и общие матчи всё ещё возможны. Только пять групп `other` недостаточно для оценки ложных срабатываний в обычном футболе. Перед обучением трёх классов нужны дополнительные проверенные отрицательные примеры.

Основной `data/annotations.json` сохраняет исходную консервативную группировку всей коллекции: `split = null`, `split_group = initial_four_compilations`. Эксперимент сознательно использует более мелкие, предварительные `event_id` и явно помечен `experimental`. Для этого эксперимента состав частей определяется отдельными манифестами; признаки `training_candidate` и `duplicate_of` в общей разметке не заменяют эти списки.

## Проверка первой нарезки

Все 263 клипа полностью декодированы без ошибок. Проверены разрешение, FPS, существование ссылок на кадры и соответствие длительности заданным границам; максимальное расхождение длительности — 0,04 секунды. SHA-256 всех четырёх исходников совпадает с первоначальной описью. Размер готовых клипов — около 320 МиБ.

В браузере отдельно проверены загрузка и воспроизведение видео, фильтры классов, поиск, переключение клипов, пустая выдача, скорость 0,5× и переход к действию. Для HTTP-просмотра проверена перемотка через сервер `serve_review.py`. Эти проверки подтверждают работу файлов и просмотра; качество семантических меток остаётся предварительным.
